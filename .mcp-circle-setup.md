# Circle MCP Server Setup Guide

## 🎯 What is MCP?

**Model Context Protocol (MCP)** allows AI assistants to integrate with external services. Circle's MCP server lets your AI IDE generate and fix code for:
- ✅ Circle Wallets (Developer Controlled & Programmable)
- ✅ Smart Contract Platform
- ✅ CCTP (Cross-Chain Transfer Protocol)
- ✅ Bridge Kit
- ✅ Gateway

## 📋 Setup Instructions

### Option 1: Claude Desktop (Recommended)

#### 1. Install Claude Desktop
Download from: https://claude.ai/download

#### 2. Create MCP Configuration File
```bash
# Create config directory if it doesn't exist
mkdir -p ~/Library/Application\ Support/Claude

# Create or edit the configuration file
cat > ~/Library/Application\ Support/Claude/claude_desktop_config.json << 'EOF'
{
  "mcpServers": {
    "circle": {
      "command": "node",
      "args": ["-e", "require('http').createServer((req,res)=>{res.writeHead(200);res.end('Circle MCP')}).listen(3000)"],
      "transport": "http",
      "url": "https://api.circle.com/v1/codegen/mcp",
      "scope": "user"
    }
  }
}
EOF
```

#### 3. Restart Claude Desktop
Close and reopen Claude Desktop to load the new configuration.

#### 4. Verify Setup
In Claude Desktop, type:
```
Can you help me generate code for Circle USDC transfers using CCTP?
```

Claude should now have access to Circle's MCP server and can generate code using Circle's APIs.

### Option 2: Claude CLI (Alternative)

#### 1. Install Claude CLI
```bash
npm install -g @anthropic-ai/claude-cli
```

#### 2. Add Circle MCP Server
```bash
claude mcp add --transport http circle https://api.circle.com/v1/codegen/mcp --scope user
```

#### 3. Verify Installation
```bash
claude mcp get circle
```

Expected output:
```json
{
  "name": "circle",
  "transport": "http",
  "url": "https://api.circle.com/v1/codegen/mcp",
  "scope": "user"
}
```

#### 4. Use in Claude CLI
```bash
claude "Generate code to transfer USDC from Ethereum Sepolia to Avalanche Fuji using CCTP V2"
```

### Option 3: VS Code with Continue Extension

#### 1. Install Continue Extension
- Open VS Code
- Go to Extensions (Cmd+Shift+X)
- Search for "Continue"
- Install the Continue extension

#### 2. Configure MCP Server
Create or edit `~/.continue/config.json`:

```json
{
  "models": [
    {
      "title": "Claude Sonnet 4.5",
      "provider": "anthropic",
      "model": "claude-sonnet-4.5",
      "apiKey": "YOUR_ANTHROPIC_API_KEY"
    }
  ],
  "mcpServers": [
    {
      "name": "circle",
      "transport": "http",
      "url": "https://api.circle.com/v1/codegen/mcp"
    }
  ]
}
```

#### 3. Restart VS Code
Close and reopen VS Code to load the configuration.

## 🔧 Troubleshooting

### Issue: "MCP server not found"
**Solution**: 
1. Check config file path: `~/Library/Application Support/Claude/claude_desktop_config.json`
2. Verify JSON syntax is valid
3. Restart Claude Desktop

### Issue: "Connection refused"
**Solution**:
1. Check internet connection
2. Verify MCP server URL: `https://api.circle.com/v1/codegen/mcp`
3. Check firewall settings

### Issue: "No code generation improvements"
**Solution**:
1. Be specific in prompts: mention "Circle", "USDC", "CCTP", etc.
2. Ask for concrete examples, not just explanations
3. Reference specific Circle products (Wallets, CCTP, Gateway)

## 📚 What Circle MCP Can Help With

### ✅ Supported Use Cases
- **CCTP Transfers**: Cross-chain USDC transfers with attestations
- **Developer Wallets**: Programmatic wallet creation and management
- **Smart Contracts**: Arc/EVM deployment scripts
- **Token Management**: USDC balance checks, approvals, transfers
- **Testnet Setup**: Faucet requests, environment configuration

### ❌ Not Supported
- Private key generation (security best practice)
- Direct blockchain writes (requires user signing)
- Production API key management (use environment variables)
